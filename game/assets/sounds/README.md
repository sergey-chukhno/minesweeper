# Game Sounds

This directory contains sound effects and background music for the Minesweeper game.

## Required Sound Files

Place the following sound files in this directory:

1. `click.wav` - Sound when clicking a cell
2. `flag.wav` - Sound when placing/removing a flag
3. `explosion.wav` - Sound when hitting a mine
4. `win.wav` - Sound when winning the game
5. `lose.wav` - Sound when losing the game
6. `hover.wav` - Sound when hovering over a cell
7. `background.mp3` - Background music for the game

## Sound File Requirements

- Sound effects should be short (0.1-1 second)
- Use WAV format for sound effects
- Use MP3 format for background music
- Keep file sizes small (under 1MB each)
- Use 16-bit PCM for WAV files
- Use 128-192kbps for MP3 files

## Example Sound Sources

You can find free sound effects at:
- freesound.org
- soundbible.com
- opengameart.org

Make sure to check the license terms before using any sound files.
